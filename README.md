# Slabikář

Hra na čtení pro předškoláky: hlásky, slabiky a slova jako ve slabikáři.
Otevři `index.html`, nebo webovou stránku na GitHub Pages.

- 6 her: první/poslední hláska, vytleskávání, najdi slabiku, slož slabiku, slož slovo, přečti
- Rodičovská část: písmenka podle slabikáře, hlas, statistiky chyb
- Vlastní hlas: v části „Pro rodiče“ → „Nahrát všechno najednou“ (nahrávky zůstávají v prohlížeči)
